# Security policy

Please report a suspected vulnerability privately through the [Serfe contact form](https://www.serfe.com/en/contact-us). Use the subject **Security vulnerability report: Serfe WordPress AI Discovery** so the report can be routed to the maintainers. Do not disclose the issue in a public GitHub issue, WordPress.org forum, discussion, or pull request before a fix is available.

Include a concise description, affected plugin version or commit, steps to reproduce, expected and actual behavior, and the potential impact. Share a minimal proof of concept if one is needed. Do not send credentials, customer data, database dumps, or other sensitive site content unless the maintainers request a secure transfer method.

We aim to acknowledge private reports within two business days and prioritize investigation and remediation according to severity. We may ask for more information, coordinate a fix, and agree on a disclosure timeline with the reporter. This is a best-effort community policy, not a commercial service-level agreement.

The policy applies to the current source and to supported public releases once they exist. If a release is no longer supported, maintainers will say so in the response and recommend a supported version.
